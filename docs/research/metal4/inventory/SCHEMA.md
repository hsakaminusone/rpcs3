# `inventory/` — schema & conventions

This directory is the **completeness spine** for the RSX → Metal 4 design work: a
mechanically-generated enumeration of everything the guest can put into RSX state,
plus a curated layer that records how each item maps to Metal 4.

Everything here is derived from the RPCS3 source tree, not hand-written. The
generator (`generate.py`) is the source of truth for *facts*; humans/agents own the
*disposition* layer.

---

## 1. The three spaces

| space | what it is | source of truth | artifact |
|---|---|---|---|
| **COMMAND** | FIFO method registers the guest writes | `gcm_enums.h` method enum | `out/rsx_state_space.csv` |
| **DECODE** | per-register bitfield layout | `rsx_decode.h` `registers_decoder<>` | `out/rsx_decode_fields.csv` |
| **VALUE** | enums a register can carry (formats, blend factors, compare functions, …) | `gcm_enums.h` / `CELL_GCM_*` | `out/rsx_value_space.csv` |
| **SHADER** | the vertex/fragment instruction encoding (opcodes, register types/precisions, instruction bitfields, program fields) | `Program/RSXVertexProgram.h`, `Program/RSXFragmentProgram.h` | `out/rsx_shader_facets.csv` |

Supporting extractions: dispatch table (`rsx_methods.cpp`), argument-table slots
(`VK/vkutils/pipeline_binding_table.h`), NV47/HW modules.

Every VALUE row carries a `block` column — the `gcm_enums.h:<line>` of the `enum`
it came from — so an anonymous `enum {}` has a stable identity even though it has
no C++ name. A slot row carries `placeholder`: the source marks such a field
invalid/derived (re-initialized at runtime), so it owns no slot.

## 2. Stable IDs

| prefix | meaning | example |
|---|---|---|
| `M_<NAME>` | a FIFO method register | `M_NV4097_SET_SURFACE_FORMAT` |
| `M_<NAME>.<field>` | a decoded bitfield of a register | `M_NV4097_SET_SURFACE_FORMAT.color_fmt_raw` |
| `V_<NAME>` | a value-space constant | `V_CELL_GCM_TEXTURE_A8R8G8B8` |
| `SH_V_*` / `SH_F_*` | a shader facet (vertex/fragment) | `SH_F_BF_OPDEST.opcode` |
| `S_<slot>` | an argument-table binding slot | `S_textures_first_bind_slot` |
| `N_<module>#<fn>` | an NV47/HW implementation function | `N_nv4097#clear` |

IDs are stable across regeneration: they are the C++ symbol names. **Never invent an
ID**; take it from the CSV.

## 3. Artifact map

```
inventory/
  generate.py            # mechanical extractor (run it, don't hand-edit output)
  validate.py            # disposition validator + merger (the curation gate)
  lint_docs.py           # design-doc linter (sentinel + table shape + coverage)
  run.sh                 # generate -> test -> validate -> lint, one shot
  test_generate.py       # extractor conformance tests
  test_validate.py       # validator tests
  SCHEMA.md              # this file
  README.md              # how to run
  out/
    SUMMARY.md           # generated: whole spine as tables, by cluster
    rsx_state_space.csv  # the spine (COMMAND) + curated columns
    rsx_decode_fields.csv
    rsx_value_space.csv
    rsx_shader_facets.csv
    rsx_binding_slots.csv
    clusters.json        # cluster -> register count
    rsx_stats.json
    clusters/<name>.csv  # per-cluster shard (the unit of work)
    dispositions/<name>.csv   # curated layer (one row per register id)
    COVERAGE.md          # generated by validate.py
```

## 4. Disposition vocabulary (the curated layer)

| value | meaning |
|---|---|
| `direct` | maps ~1:1 to a Metal 4 construct (may still need glue) |
| `reshape` | same need, different shape (e.g. render-pass object → encoder) |
| `emulate` | no native path; realised in shader / compute / host code |
| `impossible` | no Metal API path exists at all |
| `not-recommended` | expressible but a known trap |
| `moot` | the construct never appears under the RSX-first frame |
| `na` | no state / not applicable (e.g. a pure notify register) |

Scales (identical to `docs/research/metal4/README.md` §2):

- **difficulty** 1–5: 1 trivial rename · 2 mechanical · 3 real work, well-trodden ·
  4 hard/needs design · 5 unknown/impossible.
- **risk**: `low` / `med` / `high`.
- **confidence**: `[V]` verified against a primary source (code or Apple doc) ·
  `[I]` inference · `[U]` could not verify.

## 5. Per-cluster disposition CSV

Each cluster owner writes `out/dispositions/<cluster>.csv` with **exactly** these
columns, one row per `id` present in `out/clusters/<cluster>.csv`:

```csv
id,disposition,metal4_target,difficulty,risk,confidence,doc_ref,notes
M_NV4097_SET_SURFACE_FORMAT,reshape,MTL4RenderPassDescriptor attachment set,4,high,[I],10 §4.3,"colour/depth formats + AA + log2 w/h; drives pass synthesis"
```

Rules:

1. **Coverage is exact**: every `id` in the cluster shard appears once; no extras.
2. `metal4_target` names the concrete Metal 4 object/method (`MTL4RenderPassDescriptor`,
   `drawIndexedPrimitives`, `.storeAction`, …), never "see doc".
3. `doc_ref` cites the existing scopes (`10 §4.3`) when a decision already exists.
4. `notes` may be empty but must not restate the register name.
5. If a field cannot be decided, set `confidence=[U]` and put the *question* in
   `notes`.

## 6. Document templates

**Low-level design** (`design/LLD-<cluster>.md`) — one per cluster:

1. **Scope** — which IDs, what the cluster is in RSX terms.
2. **Register model** — the state, its decode, and its lifetime (dirty-bit vs value).
3. **Metal 4 mapping** — per sub-area; concrete objects/methods; the *shape change*.
4. **Impossible / not-recommended** — with the fallback actually chosen.
5. **Invariants & failure modes** — what must hold; how it breaks.
6. **Open questions** — decisions a human must make, each `[V]/[I]/[U]`.
7. **Provenance** — `file:line` refs + external sources.

**High-level design** (`design/HLD-<n>-<topic>.md`):

1. **Purpose & non-goals**
2. **Model** — RSX semantics → Metal 4 semantics, with the shape change called out
3. **Interfaces / data structures** — types, lifetimes, ownership
4. **Invariants**
5. **Failure modes & limits**
6. **Open questions**
7. **Provenance**

Every document must end with the line `<!-- doc-end -->` so loops can validate it.

## 7. Regeneration

```
python3 generate.py          # rewrites out/ ; prints stats; non-zero on sanity failure
python3 -m unittest -v       # conformance tests (must stay green)
```

`out/SUMMARY.md`, the CSVs and the JSON are **generated**; the disposition CSVs and
`design/*.md` are **curated**. When the tree changes, rerun the generator and re-check
the curated layer still covers every ID.
